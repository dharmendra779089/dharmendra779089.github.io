03 — projects

Things I've built

HAQMS — Healthcare Appointment Queue Management System
● livefull stack

A production-ready healthcare web app managing appointment queues with role-based access, secured authentication, and database-level performance tuning. Built and deployed solo.

  • Eliminated SQL injection using Prisma ORM parameterized queries and added JWT expiry + RBAC
  • Resolved N+1 query loops via Prisma include — cut report generation from O(n×5) to O(3) DB calls
  • Fixed patient check-in data races with atomic prisma.$transaction blocks
  • Migrated in-memory pagination to DB-level filtering for true scalability under load
