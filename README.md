Live Demo: `https://dharmendra779089.github.io/`

---

## 🚀 Key Architectural Features

* **Zero-Dependency Interaction Engine:** Features like the dynamic typewriter header, scrolling marquee, and contact modal run on pure, optimized Vanilla JavaScript to eliminate bundle bloat.
* **Hardware-Accelerated Canvas Particles:** Uses an HTML5 `<canvas>` background driven by an active `requestAnimationFrame` loop to render interactive ambient points cleanly without degrading CPU metrics.
* **Dynamic Mouse Radial Glow:** Real-time client-side mouse spatial coordinate tracking overlays a fluid, trailing background gradient highlight.
* **Asynchronous Scroll Reveals:** Leverages the native browser `IntersectionObserver` API to lazily trigger layout transition translations only when elements slide within viewport parameters.
* **100% Fluid Breakpoints:** Fully responsive engineering down to mobile screen viewports utilizing CSS Grid structures, clamping typography functions (`clamp()`), and media queries.
* **Embedded High-Fidelity Resume:** Seamless instant download via embedded Base64 PDF and standalone `resume.pdf`.
